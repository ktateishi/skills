# 読みやすくわかりやすい日本語のルール

文化庁の「公用文作成の考え方」、出入国在留管理庁・文化庁の「やさしい日本語ガイドライン」、本多勝一『日本語の作文技術』、textlint の技術文書向けルールなどを調べて、ルールを整理した。出典は [references/sources.md](references/sources.md) にある。

各ルールには ID（S = 構成、B = 文、W = 言葉、N = 表記）を付けた。詳細（NG例・OK例・理由・出典）は分類ごとのファイルにある。

## 使い方

### 文章を書くとき

1. 書く前に **読み手** と **目的** を決める（S-01）。読み手が決まらない場合は、依頼者に確認する。
2. 構成を決める。結論を先に置き、見出しだけ読めば全体がわかるようにする（S-02〜S-05）。
3. 本文を書く。文は短く、1文に1つの情報だけを入れる（B-01〜B-03）。
4. 書き終えたら、次の「見直すとき」の手順で全ルールを確認する。

### 文章を見直すとき（校正・レビュー）

1. 4つの詳細ファイルをすべて読む。
2. 対象の文章を **全ルール** に照らして確認する。ルールごとに、違反している箇所を洗い出す。
3. 違反箇所ごとに、ルール ID・元の文・修正案を示す。修正案は、元の意味を変えないようにする。
4. 意味が変わるおそれがある修正や、読み手によって判断が分かれる修正は、理由を添えて提案にとどめる。

完了の条件は「すべてのルールを確認し、違反箇所をすべて示した」状態である。

## ルール一覧

### S. 文書の構成 → [references/structure.md](references/structure.md)

- S-01 書く前に読み手と目的を決める
- S-02 結論を先に書き、理由や詳細を後に続ける
- S-03 タイトルで主題と文書の性格を示す
- S-04 見出しを追えば全体の内容がわかるようにする
- S-05 1つの段落では1つの話題だけを扱う
- S-06 伝えることを絞り、分量の上限を決める
- S-07 読み手の手順に沿って書き、しなくてよいことも書く
- S-08 図や表を使って視覚的に示す

### B. 文の組み立て → [references/sentence.md](references/sentence.md)

- B-01 一文を短くする（50〜60字を超えたら見直す）
- B-02 一文には1つの情報だけを入れる（一文一義）
- B-03 3つ以上の情報を並べるときは箇条書きにする
- B-04 主語と述語を明確にし、近くに置く
- B-05 主語と述語をねじれさせない
- B-06 修飾語は、修飾される語の直前に置く
- B-07 長い修飾語を先に、短い修飾語を後に置く
- B-08 基本の語順（いつ・どこで・誰が・何を・どうした）で書く
- B-09 係り方で複数の意味に取れる文を書かない
- B-10 読点は意味の切れ目に打つ（長い修飾語の境界、語順が逆のとき）
- B-11 読点は一文に3つまでを目安にする
- B-12 接続助詞「が」や中止法で文をつなぎ続けない
- B-13 同じ助詞を連続させない
- B-14 二重否定を使わない
- B-15 受け身をむやみに使わない
- B-16 指示語（これ・それ）を多用せず、指す内容の近くで使う
- B-17 接続詞は前後の論理関係に合うものを選ぶ
- B-18 同じ文末・同じ書き出しを続けない

### W. 言葉の選び方 → [references/wording.md](references/wording.md)

- W-01 回りくどい表現を削る（「することができる」→「できる」）
- W-02 重言（意味の重複）を避ける
- W-03 同じものは同じ言葉で呼ぶ（用語の統一）
- W-04 専門用語は言い換えるか、説明を付ける
- W-05 カタカナ語は、定着していないものを言い換える
- W-06 略語は、元の言葉を示してから使う
- W-07 数量・時期は具体的な数字で示す
- W-08 「等」「など」を安易に使わない
- W-09 起点は「から」、比較は「より」で書き分ける
- W-10 推量や弱い表現を避け、言い切る
- W-11 難しい漢語は和語に言い換える
- W-12 同音異義語や複数の意味を持つ言葉を避ける
- W-13 文語的な言い回しを口語にする
- W-14 敬語を重ねすぎない
- W-15 偏見や差別につながる表現を避ける
- W-16 抽象的な言葉ではなく、具体的な言葉を使う

### N. 表記 → [references/notation.md](references/notation.md)

- N-01 「です・ます」と「である」を混ぜない
- N-02 漢字を使いすぎない（漢字は3割程度、連続は5文字まで）
- N-03 形式名詞・補助動詞などはひらがなで書く
- N-04 表記ゆれをなくす
- N-05 横書きでは算用数字を使い、3桁ごとにコンマで区切る
- N-06 句読点・括弧・記号の使い方を文書内で統一する
- N-07 全角・半角の使い分けを統一し、半角カナを使わない
- N-08 ら抜き言葉を使わない
- N-09 技術文書・ビジネス文書では感嘆符や感情的な表現を控える

## ルールどうしがぶつかるとき

ルールは読み手に伝えるための手段である。ルールを守ると不自然になる場合は、読み手にとってわかりやすい方を選ぶ。たとえば、受け身は責任の所在をぼかすので避けるが、行為の主体が重要でない場合は受け身の方が自然である（B-15）。
